title: "CLI installation"

---

<Info>
  There are two ways of installing Avenue: the CLI script or <a href="/installation">
  manual installation</a>

  .
</Info>

Follow these steps to install and run all Avenue components on your operating system:

**Step 1**: Install `avenue-cli` using NPM:

```bash
npm i -g avenue-cli
```

**Step 2**: Run CLI installation:

```bash
avenue-cli install
```

or

```bash
npx avenue-cli install
```

The script will guide you through the installation process. You will have to enter project name and database connection parameters. Also, you'll be asked if you want to install Avenue Storefront and Vendor panel.

**Step 3**: After installation is done, move to the project catalog and start the servers:

```bash
cd <yourProjectName>

avenue-cli dev
```

The script automatically configures environment variables, and runs seed. The default credentials for created users are:

**Vendor:**

```
email: seller@avenuejs.com
password: secret
```

**Admin:**

```
email: admin@avenuejs.com
password: admin
```
